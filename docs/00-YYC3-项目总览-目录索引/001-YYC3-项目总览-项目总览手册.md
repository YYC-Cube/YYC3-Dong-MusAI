## 一、项目画像

| 属性 | 内容 |
| ---- | ---- |
| 项目名称 | M98 董小姐音乐宇宙（M98_DongXiaoJie） |

| 核心标签 | 东方电子 · 音乐人生态 · 粉丝互动 · React SPA · Express API |

| 价值主张 | 用数字空间承载“电子 × 东方 × 未来”的音乐叙事 |

| 品牌主色 | 紫罗兰 `#8A2BE2` × 珊瑚红 `#FF6B6B` × 深空蓝黑 `#0D1117` |

## 三、目录结构

```text
M-DongXiaoJie/
├── web_app/          React 18 粉丝网站（CRA）
├── api_service/      Express API（Mongo / SQLite / Mock 三入口）
├── content_db/       SQLite 开发库与种子数据
├── database/         运行期 SQLite 数据库
├── admin_panel/      管理后台（空壳，规划中）
├── mobile_app/       移动端（单屏，规划中）
├── marketing_tools/  营销自动化（单脚本，规划中）
├── weather/          Python MCP 天气助手
├── scripts/          启动 / 测试 / 数据库脚本
├── public/           品牌、封面、海报、音乐、多端图标
├── brand_assets/     品牌指南
└── docs/             十二阶段文档体系（本目录）
```

---

## 四、快速开始

```bash
# 后端（SQLite 演示入口）
cd api_service && npm install && npm start

# 前端
cd web_app && npm install && npm start

# 访问
# Web   http://localhost:3000
# API   http://localhost:4000
# Docs  http://localhost:4000/docs
```

> 详细步骤与故障排查见 [0302-开发环境指南](../03-YYC3-项目开发-实施阶段/0302-YYC3-项目开发-开发环境指南.md)。
