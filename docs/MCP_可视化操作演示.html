🚀 MCP 操作演示

跟着步骤走，3分钟学会MCP！

步骤1：找到MCP配置界面

MCP通常在这些地方：

📁 VS Code → 侧边栏 → 扩展
🌐 网页应用 → 设置 → MCP配置
💻 桌面应用 → 工具 → 配置
💡 提示：如果找不到，试试搜索"MCP"、"服务器"或"配置"
⬇️

步骤2：启用MCP服务器

看到这样的界面：

MCP服务器管理

AI服务器
http://localhost:8000
● 离线
数据分析服务器
http://localhost:8001
● 离线
🎯 操作：点击右边的开关按钮，从灰色变成绿色就是启用了！
⬇️

步骤3：配置文件方式（可选）

如果更喜欢改配置文件：

{ "mcp_servers": [ { "name": "我的AI服务器", "address": "http://localhost:8000", "enabled": true }, { "name": "数据分析服务器", "address": "http://localhost:8001", "enabled": false } ] }
📝 说明："enabled": true 表示启用，"enabled": false 表示禁用
⬇️

步骤4：验证是否成功

✅ 成功的标志

● 界面显示绿色"已连接"
● 服务器状态显示"运行中"
● 没有红色错误提示

❌ 常见问题

问题1：找不到MCP在哪里
解决：按 Ctrl+Shift+P (Mac: Cmd+Shift+P) 搜索"MCP"

问题2：开关点了没反应
解决：等待3-5秒，或刷新页面重试

问题3：显示"连接失败"
解决：检查服务器地址是否正确，确保服务器在运行

🎉 完成！

现在您已经成功启用了MCP！可以开始使用各种AI功能了。

记住：MCP就像一个电灯开关，开了就能用，关了就不能用。不要想得太复杂！
