## 一、适用读者

| 角色 | 关注内容 |
| ---- | -------- |
| 访客 | 浏览资料、试听作品 |

## 二、快速上手（访客）

1. 打开站点首页。
2. 首屏为艺术家资料：姓名、M98 标识、流派标签、统计数字。
3. 向下滚动浏览“最新作品”。
4. 点击作品卡片或底部播放器播放按钮试听。
5. 继续向下查看虚拟演出、AI 创作、数据看板、粉丝心声与社交聚合。

## 三、播放器操作

| 操作 | 方法 | 反馈 |
| ---- | ---- | ---- |
| 播放 / 暂停 | 点击 ▶ / ⏸ | 音频播放或暂停，进度条前进 |
| 上一首 | 点击 ⏮ | 切换到上一曲 |
| 下一首 | 点击 ⏭ | 切换到下一曲 |
| 跳转进度 | 点击进度条 | 从点击位置继续播放 |
| 音量 | 拖动音量滑块 | 实时调整 |
| 自动续播 | 等待当前曲结束 | 自动进入下一首 |

> 曲库位于 `public/D-Music/`，共 11 首。若无法播放，请检查网络或浏览器音频权限。

## 四、粉丝互动

| 功能 | 操作 | 说明 |
| ---- | ---- | ---- |

## 七、常见问题

| 问题 | 原因 | 解决 |
| ---- | ---- | ---- |
| 页面一直载入 | 后端未启动 | 启动 API 后刷新 |
| 显示“连接失败” | API 地址不可达 | 检查 `apiConfig.js` 与端口 |
| 图片不显示 | 资源路径错误 | 确认使用 `assets.js` |
| 音频无声 | 浏览器自动播放限制 | 先点击页面再播放 |
| 音频 404 | 文件名变更 | 同步更新 `assets.js` |
| 手机端排版异常 | 未适配小屏 | 使用响应式断点（规划中） |

## 八、无障碍与体验建议

- 图片均提供 `alt` 文本。
- 播放器按钮建议补充 `aria-label`。
- 键盘操作与焦点管理待完善。
- 建议提供字幕/歌词区域（规划中）。
