🚀 MCP 使用演示

3分钟学会启用和使用 Model Context Protocol

💡 什么是MCP？

MCP = Model Context Protocol（模型上下文协议）

简单理解：MCP是让AI连接各种工具的"桥梁"

你的问题 → AI → MCP → 工具服务 → 更好的答案
1 打开MCP配置界面

在你的应用中找到并点击 "MCP配置" 选项卡

2 添加MCP服务器

点击 "添加服务器" 按钮，填写以下信息：

服务器名称： 本地代码助手
服务器地址： http://localhost:8000
状态： 启用
3 保存配置

点击 "保存配置" 按钮完成设置

🎉 恭喜！MCP已成功启用 现在你可以正常与AI对话，享受更强大的功能！
📊 MCP效果对比

❌ 没有MCP的情况

你问：帮我分析这个CSV文件

AI答：我无法直接访问文件，请你描述数据内容...

✅ 有MCP的情况

你问：帮我分析这个CSV文件

AI答：我已通过数据分析服务处理了你的文件：
• 共1000行数据
• 发现3个异常值
• 销售趋势呈上升状态
• [附带图表和详细报告]

🔧 常用MCP服务器
代码生成服务： http://localhost:8000
数据分析服务： http://localhost:8080
文档搜索服务： http://localhost:9000
API调用服务： http://localhost:7000
