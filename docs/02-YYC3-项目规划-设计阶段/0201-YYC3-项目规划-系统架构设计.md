## 一、架构现状

```text
┌───────────────────────────────────────────────────────────────┐
│                         浏览器 / 移动端                        │
│  React 18 SPA（CRA） · framer-motion · styled-components       │
│  HomePage ──> components/advanced/* ──> services/apiService   │
└───────────────────────────┬───────────────────────────────────┘
                            │ HTTP / JSON（axios，baseURL :4000）
┌───────────────────────────▼───────────────────────────────────┐
│                     Express API（:4000）                       │
│  /api/artist   /api/music   /api/fans   /api/content          │
│  helmet · cors · rate-limit · swagger                          │
├───────────────────────────────────────────────────────────────┤
│  数据访问（目标：PostgreSQL 15 唯一事实源）                     │
│  ├── pg ──────────> PostgreSQL 15（yyc3_music:5433 / NAS）      │
│  ├── Mongoose 6 ──> MongoDB 5.0（遗留，冻结）                  │
│  └── sqlite3 / Mock（本地调试，冻结）                          │
└───────────────────────────────────────────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────────────┐
│  public/D-* 静态资产（Logo / 主图 / 封面 / 海报 / MP3 / 图标）  │
└───────────────────────────────────────────────────────────────┘
```

## 二、分层职责

| 层 | 职责 | 关键文件 |
| -- | ---- | -------- |
| 表现层 | 页面编排、动画、组件渲染 | `web_app/src/pages/HomePage.jsx`、`components/advanced/*` |
| 服务层 | HTTP 封装、错误拦截、接口常量 | `services/apiService.js`、`apiConfig.js` |
| 资产层 | 统一资产路径解析 | `config/assets.js` |
| 路由层 | 接口定义、Swagger 注释 | `api_service/src/routes/*.js` |
| 模型层 | Schema 与约束 | `models/Artist.js`、`models/Release.js` |
| 数据层 | Mongo / SQLite / Mock | `server*.js` |

## 三、模块与依赖

| 模块 | 依赖 | 说明 |
| ---- | ---- | ---- |
| HomePage | apiService、advanced/*、assets | 单页聚合 8 个区块 |
| AdvancedMusicPlayer | assets、HTMLAudioElement | 真实音频播放 |
| FanInteractionHub | 本地状态 | 互动演示 |
| MusicDataAnalytics | 静态/模拟数据 | 图表展示 |
| API routes | models / db | 四组资源 |
| weather (MCP) | FastMCP | 与主业务弱耦合，独立进程 |

## 四、接口契约

统一响应：`{ success: boolean, data?: any, message?: string }`。

| 资源 | 端点 | 说明 |
| ---- | ---- | ---- |
| Artist | `GET /api/artist/profile` | 资料（不存在时自动建档） |
| Artist | `GET /api/artist/stats` | 聚合统计 |
| Artist | `GET /api/artist/latest-activity` | 最新动态 |
| Music | `GET /api/music/releases` | 分页列表 |
| Music | `GET /api/music/featured` | 播放量 Top 3 |
| Music | `GET /api/music/latest` | 最新单曲 |
| Music | `POST /api/music/:id/play` | 播放计数 |
| Fans | `GET /api/fans/wall` | 留言墙 |
| Fans | `GET /api/fans/stats` | 粉丝画像 |
| Content | `GET /api/content/{exclusive,blog,events}` | 内容运营 |

Swagger：`http://localhost:4000/docs`。

## 五、数据模型

**Artist**：`artistId`（唯一）、`name`、`bio`、`genres[]`、`stats{monthlyListeners,totalPlays,followers}`、`socialLinks{}`、`discography[]`。

**Release**：`title`、`artistId`、`artist(ObjectId)`、`releaseDate`、`type(enum)`、`coverArt`、`tracks[]`、`stats{plays,downloads,shares}`、`isExclusive`。

**SQLite**：`artists`、`releases`、`fan_messages`，JSON 字段以 TEXT 存储。

## 六、关键设计决策

| 决策 | 现状 | 建议 |
| ---- | ---- | ---- |
| 数据源 | 三套并存 | **收敛为单一事实源**：开发 SQLite、生产 MongoDB，Mock 仅测试 |
| 状态管理 | 组件内 useState | 跨区块状态引入 Zustand / Context |
| 样式 | styled-components + 内联 | 统一设计令牌（CSS Variables） |
| 路由 | 单路由 | 按 `music/about/community/exclusive` 拆分 |
| 资产 | 路径散落 | 统一 `assets.js`（已落地） |

## 七、数据源决策（2026-11-07 确认）

| 项 | 决策 |
| -- | ---- |
| 主数据库 | **PostgreSQL 15** |
| 本地实例 | 数据库 `yyc3_music`，端口 `5433`，用户 `yanyu`（本机免密） |
| NAS 容器 | Docker 服务 `yyc3-music`（`musai` 栈为另一套并行服务，不属本项目） |
| 音乐 API | 通过 `ssh yyc3-45` 访问 |
| 唯一事实源 | PostgreSQL 15（MongoDB / SQLite / Mock 降级为遗留或本地调试） |

### 7.1 连接参数（占位，真实密码由密钥管理注入）

```bash
PGHOST=localhost
PGPORT=5433
PGDATABASE=yyc3_music
PGUSER=yanyu
# 本机 trust/peer 免密；NAS/远程由密钥管理注入
PGPASSWORD=
```

### 7.2 迁移状态

| 项 | 状态 |
| -- | :--: |
| 目标架构确认 | ✅ |
| `api_service` PG 适配层 | ⬜ 待实现 |
| 数据迁移脚本（Mongo/SQLite → PG） | ⬜ 待编写 |
| NAS `yyc3-music` 联调 | ⬜ 待联调 |
| 遗留 Mongo / SQLite 入口 | 🟡 保留但冻结 |

> **已确认**：NAS 截图中的 `musai` 栈（`musai-backend`、`musai-frontend`、`musai-mysql`、`musai-redis`）为另一套并行服务；本项目目标仍为 `yyc3-music`（PostgreSQL 15）。

## 八、部署拓扑（建议）

```text
Internet
  │
  ▼
Nginx（TLS / 静态资源 / gzip / 缓存）
  ├── /            → web_app 构建产物
  └── /api         → Express（PM2 / Docker）
                        └── PostgreSQL 15（yyc3_music）
```

## 九、演进路线

1. **收敛**：删除重复入口与 Mock 路由，冻结接口契约；落地 PostgreSQL 15 适配层。
2. **加固**：鉴权、校验、限流、错误码、结构化日志。
3. **提速**：Vite + TypeScript + 代码分割 + 图片/音频懒加载。
4. **扩展**：后台管理、移动端、真实 AI 服务、可观测性。
