# MCP (Model Context Protocol) 使用指南

## 🎯 MCP是什么？如何启用和使用？

**简单理解**：MCP是一个帮助AI连接不同服务的协议。想象它是一个"翻译器"，让AI能够与各种工具对话。

### 🚀 3分钟快速上手

#### Step 1: 理解MCP的作用

```text
你的问题 → AI → MCP服务器 → 具体工具/服务 → 返回结果
```

例如：

- 问"分析这个数据" → AI通过MCP → 连接数据分析服务 → 返回分析结果
- 问"生成代码" → AI通过MCP → 连接代码生成服务 → 返回代码

#### Step 2: 如何启用MCP（3个步骤）

##### 方法1: 通过界面操作（推荐）

1. **打开MCP配置页面**
   - 在你的应用中找到"MCP配置"选项卡
   - 点击进入

2. **添加MCP服务器**

   ```text
   服务器名称：本地代码助手
   服务器地址：http://localhost:8000
   状态：✅ 启用
   ```

3. **保存配置**
   - 点击"保存配置"按钮
   - 看到"配置已保存"提示

##### 方法2: 通过配置文件

创建 `Craft_mcp_settings.json` 文件：

```json
{
  "mcp_servers": [
    {
      "name": "本地代码助手",
      "address": "http://localhost:8000",
      "enabled": true
    }
  ]
}
```

#### Step 3: 如何使用MCP

**启用后，MCP会自动工作**：

- 你正常向AI提问
- AI自动判断是否需要调用MCP服务
- 如果需要，AI会通过MCP获取更准确的答案

## 🎯 MCP控制方式总览

MCP **不支持按键控制**，而是通过以下现代化方式进行管理：

### 1. GUI 可视化控制 ✨

#### 服务器管理面板

```text
┌─────────────────────────────────────┐
│ 🟢 本地推理服务器                     │
│    http://localhost:8000            │
│                          [🔄] [🗑️] │
└─────────────────────────────────────┘
```

#### 操作按钮

- **🔄 启用/禁用切换**：一键开关服务器
- **🗑️ 删除**：移除服务器配置
- **➕ 添加**：新增服务器
- **💾 保存**：持久化配置
- **📤 导出**：备份配置文件
- **📥 导入**：恢复配置

### 2. 配置文件控制 📝

#### JSON配置格式

```json
{
  "mcp_servers": [
    {
      "name": "本地推理服务器",
      "address": "http://localhost:8000", 
      "enabled": true
    }
  ]
}
```

#### 配置存储方式

- **浏览器存储**：localStorage自动保存
- **本地文件**：Craft_mcp_settings.json
- **插件集成**：支持IDE插件环境

### 3. API程序控制 🔧

#### 服务器状态管理

```javascript
// 启用/禁用服务器
const handleToggleServer = (id) => {
  setMcpServers(mcpServers.map(server => 
    server.id === id ? { ...server, enabled: !server.enabled } : server
  ));
};

// 添加新服务器  
handleAddServer({
  name: "新服务器",
  address: "http://localhost:9000",
  enabled: true
})

// 删除服务器
handleRemoveServer(serverId)
```

## ⚡ 为什么不用按键控制？

### 按键控制的局限 ❌

- **复杂性高**：多服务器管理需要复杂的按键组合
- **记忆负担**：用户需要记住大量快捷键
- **状态不明**：无法直观显示服务器状态
- **操作风险**：误操作可能导致配置错误

### GUI控制的优势 ✅

- **可视化状态**：🟢启用 🔴禁用 一目了然
- **直观操作**：点击按钮即可完成操作
- **批量管理**：支持多服务器同时管理
- **配置导入导出**：支持备份和分享
- **实时预览**：JSON配置实时显示

## 📋 最佳实践

### 1. 服务器命名规范

- 使用描述性名称：`本地推理服务器`、`数据分析服务`
- 避免特殊字符和中文标点

### 2. 地址格式标准

- 完整URL：`http://localhost:8000`
- 包含协议：`http://` 或 `https://`
- 明确端口号

### 3. 配置管理建议

- 定期导出配置备份
- 测试环境和生产环境分别配置
- 及时清理无用的服务器配置

## 🔧 故障排除

### 常见问题

1. **服务器无法启用**：检查地址是否正确，服务是否运行
2. **配置导入失败**：确保JSON格式正确，无语法错误
3. **保存失败**：检查浏览器存储权限，清理localStorage

### 解决方案

```javascript
// 错误处理示例
try {
  localStorage.setItem("Craft_mcp_settings", JSON.stringify(config));
  alert("MCP 配置已保存！");
} catch (error) {
  alert(`保存失败: ${error.message}`);
}
```
