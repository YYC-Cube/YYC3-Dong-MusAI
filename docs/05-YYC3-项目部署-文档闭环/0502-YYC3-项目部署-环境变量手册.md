## 一、约定与优先级

| 规则 | 说明 |
| ---- | ---- |
| 模板文件 | 各端 `.env.example` 入库，真实 `.env` 不入库 |
| 优先级 | Shell 环境变量 > `.env` > 代码默认值 |
| 前缀 | 浏览器端仅暴露 `VITE_*`（Vite）；管理后台同为 `VITE_*` |
| 密钥 | 标注“密钥”的变量禁止写入仓库、日志与截图 |
| 生产 | 由密钥管理系统或部署平台注入，容器内不落盘 |

**模板文件索引**

| 端 | 模板 |
| -- | ---- |
| API 服务 | `api_service/.env.example` |
| Web 前端 | `web_app/.env.example` |
| 管理后台 | `admin_panel/.env.example` |
| 容器编排 | `docs/05-YYC3-项目部署-文档闭环/0501-YYC3-项目部署-部署运维指南.md` |

## 三、API 服务变量（`api_service`）

### 3.1 服务

| 变量 | 必填 | 默认 | 示例 | 说明 |
| ---- | :--: | ---- | ---- | ---- |
| `PORT` | 否 | `4000` | `4000` | HTTP 监听端口 |
| `NODE_ENV` | 否 | `development` | `production` | `development` / `test` / `production` |
| `FRONTEND_URL` | 是 | `http://localhost:3000` | `https://m98.example.com` | CORS 白名单 |

### 3.2 PostgreSQL 15（唯一事实源）

| 变量 | 必填 | 默认 | 示例 | 说明 |
| ---- | :--: | ---- | ---- | ---- |
| `PGHOST` | 否 | `localhost` | `localhost` / `db` | 数据库主机 |
| `PGPORT` | 否 | `5433` | `5433`（本机）/ `5432`（容器） | 数据库端口 |
| `PGDATABASE` | 否 | `yyc3_music` | `yyc3_music` | 数据库名 |
| `PGUSER` | 否 | `yanyu` | `yanyu` | 数据库用户 |
| `PGPASSWORD` | 否 | 空 | `********` | **密钥**；本机 trust/peer 免密 |
| `PGSCHEMA` | 否 | `m98` | `m98` | 适配层 schema，与 `public` 隔离 |
| `PGSSL` | 否 | `false` | `true` | 远程连接是否启用 SSL |
| `PGPOOL_MAX` | 否 | `10` | `10` | 连接池上限 |
| `PGTEST_ADMIN_DATABASE` | 否 | `yyc3_music` | `yyc3_music` | 测试库创建时的管理库 |
| `PGTEST_DATABASE` | 否 | `yyc3_music_test` | `yyc3_music_test` | 自动化测试库 |

### 3.3 归档迁移源（仅 `pg:import` / `pg:verify`）

| 变量 | 必填 | 默认 | 示例 | 说明 |
| ---- | :--: | ---- | ---- | ---- |
| `DB_PATH` | 否 | `../../database/m98_database.sqlite` | 同左 | 归档 SQLite 迁移源；服务运行期不再读取 |

### 3.4 鉴权与管理账号

| 变量 | 必填 | 默认 | 示例 | 说明 |
| ---- | :--: | ---- | ---- | ---- |
| `JWT_SECRET` | 生产必填 | 开发回退值 | 64 位随机串 | **密钥**；生产缺失将拒绝鉴权 |
| `JWT_EXPIRES_IN` | 否 | `8h` | `2h` / `8h` / `7d` | Token 有效期 |
| `ADMIN_USERNAME` | 否 | `admin` | `m98-admin` | 管理后台账号 |
| `ADMIN_PASSWORD` | 生产必填 | `m98-admin-dev`（仅非生产） | 强密码 | **密钥**；生产必须覆盖 |

| `CLOUDINARY_CLOUD_NAME` | 否 | 空 | Cloudinary 云名 |
| `CLOUDINARY_API_KEY` | 否 | 空 | **密钥** |
| `CLOUDINARY_API_SECRET` | 否 | 空 | **密钥** |
| `SMTP_HOST` | 否 | 空 | 邮件服务器 |
| `SMTP_PORT` | 否 | `587` | 邮件端口 |
| `SMTP_USER` | 否 | 空 | 邮件账号 |
| `SMTP_PASS` | 否 | 空 | **密钥** |
| `WEIBO_APP_KEY` / `WEIBO_APP_SECRET` | 否 | 空 | 微博接入（预留） |

## 四、Web 前端变量（`web_app`）

| 变量 | 必填 | 默认 | 示例 | 说明 |
| ---- | :--: | ---- | ---- | ---- |
| `VITE_API_BASE_URL` | 否 | `http://localhost:4000` | `https://api.example.com` | API 基地址 |
| `BASE_URL` | 否 | Vite 内置 `/` | `/` | 静态资源前缀，由 `vite.config.mjs` 控制，通常无需设置 |

> 开发代理在 `web_app/vite.config.mjs` 的 `server.proxy` 中配置，默认 `http://localhost:4000`。

## 五、管理后台变量（`admin_panel`）

| 变量 | 必填 | 默认 | 示例 | 说明 |
| ---- | :--: | ---- | ---- | ---- |
| `VITE_API_BASE_URL` | 否 | 空 | `https://api.example.com` | 留空时走 Vite 代理 |
| `VITE_PROXY_TARGET` | 否 | `http://localhost:4000` | `http://localhost:4000` | 仅开发代理生效 |

> Vite 仅暴露 `VITE_*`；`vite.config.ts` 通过 `loadEnv` 读取 `VITE_PROXY_TARGET`。

## 六、迁移脚本变量

迁移脚本复用 PostgreSQL 变量，并额外读取 SQLite 源路径：

```bash
PGHOST=localhost
PGPORT=5433
PGDATABASE=yyc3_music
PGUSER=yanyu
PGPASSWORD=
PGSCHEMA=m98
PGSSL=false
DB_PATH=../../database/m98_database.sqlite
```

| 脚本 | 依赖变量 |
| ---- | -------- |
| `npm run pg:migrate` | `PG*`、`PGSCHEMA` |
| `npm run pg:import` | `PG*`、`PGSCHEMA`、`DB_PATH` |
| `npm run pg:seed:content` | `PG*`、`PGSCHEMA` |
| `npm run pg:verify` | `PG*`、`PGSCHEMA`、`DB_PATH` |
| `npm test` / `npm run test:pg:setup` | `PG*`、`PGTEST_DATABASE`、`PGTEST_ADMIN_DATABASE` |

## 八、校验规则

| 变量 | 规则 |
| ---- | ---- |
| `PORT` / `PGPORT` | 整数，`1–65535` |
| `NODE_ENV` | `development` / `test` / `production` |
| `PGSSL` | `true` / `false` |
| `FRONTEND_URL` / `VITE_API_BASE_URL` | 合法 URL，生产必须 HTTPS |
| `JWT_SECRET` | 生产 ≥ 32 字符，推荐 64 |
| `ADMIN_PASSWORD` | 生产 ≥ 12 字符，含大小写、数字、符号 |
| `MAX_FILE_SIZE` | 正整数，建议 ≤ 50 MB |

启动时建议执行：

```bash
node -e "['PGPORT','PORT'].forEach(k=>{const v=process.env[k]; if(v&&(Number(v)<1||Number(v)>65535)) throw new Error(k+' 非法')})"
```

## 九、故障排查

| 现象 | 可能原因 | 处理 |
| ---- | -------- | ---- |
| `ECONNREFUSED 5433` | PG 未启动或端口错误 | `pg_isready -h localhost -p 5433` |
| `password authentication failed` | 密码错误或未注入 | 检查 `PGPASSWORD`；本机应为空 |
| `database "yyc3_music" does not exist` | 数据库未创建 | 先创建数据库再执行迁移 |
| 登录返回 503 | `JWT_SECRET` 缺失（生产） | 注入密钥 |
| 登录返回 401 | 账号密码不匹配 | 核对 `ADMIN_USERNAME` / `ADMIN_PASSWORD` |
| 管理后台 401 循环 | Token 失效或时钟漂移 | 清理 localStorage 后重登 |
| CORS 报错 | `FRONTEND_URL` 未包含来源 | 更新白名单 |
| 前端请求 404 | `VITE_API_BASE_URL` 配置错误 | 检查 `.env` 并重启 |

## 十、安全要求

1. `.env` 永不入库；`.env.example` 只放占位值。
2. `JWT_SECRET`、`ADMIN_PASSWORD`、`PGPASSWORD` 必须由密钥管理注入。
3. 生产禁止使用 `m98-admin-dev` 与开发 JWT 回退值。
4. 日志不得打印完整 Token、密码与连接串。
5. 定期轮换密钥；轮换后使旧 Token 失效。
6. 远程 PostgreSQL 必须启用 `PGSSL=true` 并校验证书。
