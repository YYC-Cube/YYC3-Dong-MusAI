## 🎨 视觉设计系统

### 色彩方案

- **主色调**:
  - 紫色 (#8A2BE2) - 神秘、高贵
  - 珊瑚色 (#FF6B6B) - 温暖、活力
- **背景色**: 深色系渐变 (#0D1117 → #161B22)
- **文字色**: 层次化灰色系统

### 动画系统

- **入场动画**: opacity + transform
- **悬停效果**: scale + translateY
- **过渡动画**: 0.3s ease缓动
- **粒子动画**: 实时数学计算
- **音乐可视化**: 音频响应动画

### 响应式设计

- **断点**: 768px, 1024px, 1440px
- **网格系统**: CSS Grid + Flexbox
- **字体缩放**: rem + vw单位
- **触摸优化**: 移动端友好

## 🛠️ 技术架构

### 前端技术栈

- **框架**: React 18.2.0
- **动画**: Framer Motion 8.5.0
- **样式**: Styled Components 5.3.6
- **路由**: React Router DOM 6.8.0
- **HTTP**: Axios 1.3.0

### 组件架构

```text
src/
├── components/
│   ├── advanced/          # 高级功能组件
│   ├── artist_profile/    # 艺术家相关
│   ├── music_player/      # 音乐播放
│   └── social/           # 社交功能
├── pages/                # 页面组件
├── services/             # API服务
└── styles/              # 全局样式
```

### 状态管理

- **本地状态**: useState + useEffect
- **数据获取**: 自定义API服务
- **缓存策略**: 内存缓存 + 实时更新
