# MCP 超简单使用教程

## 🤔 什么是MCP？
**MCP = Model Context Protocol（模型上下文协议）**

简单说：MCP是让AI连接各种工具的"桥梁"

```
你的问题 → AI → MCP → 工具服务 → 更好的答案
```

## 🚀 3步启用MCP

### Step 1: 打开配置界面
在你的应用中找到并点击 **"MCP配置"** 选项卡

### Step 2: 添加服务器
点击 **"添加服务器"**，填写：
- **名称**：`本地助手`
- **地址**：`http://localhost:8000` 
- **状态**：✅ 启用

### Step 3: 保存
点击 **"保存配置"** 按钮

✅ **完成！MCP已启用**

## 💫 MCP自动工作

启用后，你**无需任何额外操作**：
- 正常向AI提问
- AI自动判断是否需要调用MCP
- 如果需要，AI通过MCP获取更准确答案

## 🎯 实际效果对比

### 没有MCP的情况：
```
你问：帮我分析这个CSV文件
AI回答：我无法直接访问文件，请你描述数据内容...
```

### 有MCP的情况：
```
你问：帮我分析这个CSV文件  
AI回答：我已通过数据分析服务处理了你的文件：
- 共1000行数据
- 发现3个异常值
- 销售趋势呈上升状态
- [附带图表和详细报告]
```

## 🔧 常见MCP服务器类型

### 1. 代码生成服务
```
地址：http://localhost:8000
功能：生成高质量代码
```

### 2. 数据分析服务  
```
地址：http://localhost:8080
功能：分析CSV、Excel等数据文件
```

### 3. 文档搜索服务
```
地址：http://localhost:9000  
功能：搜索项目文档和知识库
```

### 4. API调用服务
```
地址：http://localhost:7000
功能：调用第三方API接口
```

## ⚠️ 注意事项

### 启用前确认：
1. **服务已运行**：确保对应端口的服务在运行
2. **地址正确**：检查URL格式是否正确
3. **网络通畅**：确保AI能访问该地址

### 故障排除：
- **服务器显示红色**：服务未启动或地址错误
- **配置保存失败**：检查浏览器权限
- **MCP无响应**：重启服务器或重新配置
