## 一、环境要求

| 组件 | 最低版本 | 推荐 |
| ---- | -------- | ---- |
| Node.js | 18 LTS | 20 / 22 LTS |
| npm | 9 | 10+ |
| Python（可选，MCP） | 3.10 | 3.11 |
| MongoDB（可选） | 6.0 | 7.0 |
| SQLite | 3.35 | 3.45 |
| 浏览器 | Chrome 120 | 最新 |

## 二、目录与入口

| 模块 | 目录 | 入口 | 默认端口 |
| ---- | ---- | ---- | :------: |
| Web 前端 | `web_app/` | `src/index.js` | 3000 |
| API（Mongo） | `api_service/` | `src/server.js` | 4000 |
| API（SQLite） | `api_service/` | `src/server-sqlite.js` | 4000 |
| API（Mock） | `api_service/` | `src/server-mock.js` | 4000 |
| 天气 MCP | `weather/` | `weather.py` | 独立进程 |

> 三个 API 入口**端口相同、互斥**，同一时刻只能启动一个。

## 三、安装与启动

### 3.1 前端

```bash
cd web_app
npm install
npm start
# http://localhost:3000
# 注：prestart 会自动执行 scripts/sync-assets.js，将根 public/ 资产同步到 web_app/public
```

### 3.2 后端（SQLite，推荐本地）

```bash
cd api_service
npm install
npm run start:sqlite     # 若脚本缺失，直接 node src/server-sqlite.js
```

### 3.3 后端（MongoDB）

```bash
# 启动数据库
docker run -d --name m98-mongo -p 27017:27017 mongo:7

# 配置并启动
cd api_service
cp .env.example .env
npm start
```

### 3.4 一键脚本

```bash
./scripts/start_dev.sh        # 启动开发服务
./scripts/stop_dev.sh         # 停止
./scripts/test_api.sh         # 接口冒烟
```

### 3.5 管理后台（Vue 3 + Vite + TS）

```bash
cd admin_panel
npm install
npm run dev                   # http://localhost:3032
npm run build                 # 类型检查 + 生产构建
npm run preview               # http://localhost:3033
```

- 开发默认账号：`admin` / `m98-admin-dev`（生产必须通过 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 覆盖）。
- 登录接口：`POST /api/auth/login`；仪表盘接口：`GET /api/admin/dashboard`（Bearer Token）。
- 资产由 `predev` / `prebuild` 自动从根 `public/` 同步到 `admin_panel/public/`。

### 3.6 PostgreSQL 迁移

```bash
cd api_service
npm run pg:migrate     # 建立 m98 schema 与表结构
npm run pg:import      # SQLite → PostgreSQL 幂等导入
npm run pg:verify      # 对比行数与总播放量
```

> 详细说明见 [0503-PostgreSQL 适配与迁移指南](../05-YYC3-项目部署-文档闭环/0503-YYC3-项目部署-PostgreSQL适配与迁移指南.md)，变量见 [0502-环境变量手册](../05-YYC3-项目部署-文档闭环/0502-YYC3-项目部署-环境变量手册.md)。

## 四、环境变量

`.env` 必须纳入版本管理的是 **`.env.example`**，真实密钥只存在本地/部署平台。

| 变量 | 说明 | 示例 |
| ---- | ---- | ---- |
| `PORT` | API 端口 | `4000` |
| `NODE_ENV` | 运行环境 | `development` |
| `MONGODB_URI` | Mongo 连接串 | `mongodb://localhost:27017/m98` |
| `FRONTEND_URL` | CORS 白名单 | `http://localhost:3000` |
| `JWT_SECRET` | JWT 密钥 | 由密钥管理系统注入 |
| `DB_PATH` | SQLite 路径 | `../database/m98_database.sqlite` |

> 当前 `api_service/.env` 含明文密钥，见 [0701-安全审计报告](../07-YYC3-项目合规-安全保障/0701-YYC3-项目合规-安全审计报告.md)。

## 五、数据源切换

**唯一事实源（2026-11-07 确认）**：PostgreSQL 15。

| 场景 | 数据库 | 连接 |
| ---- | ------ | ---- |
| 本地主库 | PostgreSQL 15 · `yyc3_music` | `yanyu@localhost:5433`（本机免密） |
| NAS 容器 | Docker `yyc3-music` | 由 NAS 网络暴露；`musai` 为并行栈 |
| 音乐 API | 经 `ssh yyc3-45` 访问 | 运维提供跳板 |
| 遗留调试 | MongoDB / SQLite / Mock | 冻结，不再新增功能 |

| 变量 | 说明 | 示例 |
| ---- | ---- | ---- |
| `PGHOST` | 数据库主机 | `localhost` |
| `PGPORT` | 端口 | `5433` |
| `PGDATABASE` | 数据库名 | `yyc3_music` |
| `PGUSER` | 用户 | `yanyu` |
| `PGPASSWORD` | 密码 | 本机留空（trust/peer）；远程注入 |

> 当前 `api_service` 仍为 Mongo / SQLite 实现，PG 适配层为待办项；迁移前请勿删除旧入口。

## 六、调试

| 目标 | 方法 |
| ---- | ---- |
| 接口文档 | `http://localhost:4000/docs` |
| 健康检查 | `curl localhost:4000/health` |
| 前端代理 | `web_app/package.json` 的 `proxy` 指向 `:4000` |
| 网络面板 | 检查 `/D-Music/*.mp3` 与 `/D-cover/*.jpg` 是否 200 |
| 播放器 | 控制台查看 `音频播放失败` 告警 |

## 七、常见故障

| 现象 | 原因 | 处理 |
| ---- | ---- | ---- |
| `EADDRINUSE` | `server.js` 重复 `listen` | 删除末尾第二次 `app.listen` |
| Mongo 连接失败 | 未启动 / URI 错误 | 启动容器并核对 `MONGODB_URI` |
| 页面一直“载入中” | API 未启动 | 启动后端并检查 `/health` |
| 图片/音频 404 | 引用了 `/assets/**` | 改用 `config/assets.js` |
| `npm install` 失败 | Node 版本过低 / 网络 | 升级 Node，使用国内镜像 |
| `sqlite3` 编译失败 | 缺少构建工具 | macOS `xcode-select --install` |

## 八、开发约定

1. 端口遵循团队规范逐步迁移至 3030+。
2. 新文件必须包含 YYC³ 代码标头。
3. 资产引用统一走 `assets.js`。
4. 提交前执行 `npm run lint`（待接入）与静态检查。
5. 详细测试见 [0402-测试方案与用例](../04-YYC3-项目测试-审核阶段/0402-YYC3-项目测试-测试方案与用例.md)。
