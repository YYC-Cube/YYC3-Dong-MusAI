## 四、实现规范提醒

1. 新组件使用 PascalCase，文件名与组件同名。
2. 所有资产引用必须经 `config/assets.js`，禁止硬编码 `/assets/**`。
3. 接口响应保持 `{ success, data, message }` 契约。
4. 每个新增文件补充 YYC³ 代码标头（见 1001）。
