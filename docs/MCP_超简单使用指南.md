# MCP 超简单使用指南 🚀

## 📍 第一步：找到MCP在哪里

MCP通常在以下位置：
- **VS Code**：侧边栏的"扩展"标签页
- **网页应用**：设置菜单 → "MCP配置"
- **桌面应用**：工具栏 → "配置" → "MCP服务器"

## 📍 第二步：启用MCP（3种方法任选一种）

### 方法1：图形界面（推荐，最简单）
```
1. 点击"MCP配置"按钮
2. 看到服务器列表
3. 点击服务器右边的开关按钮 🔄
4. 绿色=启用 ✅，红色=禁用 ❌
```

### 方法2：配置文件
```
1. 找到配置文件（通常叫 settings.json 或 config.json）
2. 改成这样：
   {
     "mcp_servers": [
       {
         "name": "我的服务器",
         "address": "http://localhost:8000",
         "enabled": true
       }
     ]
   }
3. 保存文件
```

### 方法3：命令行（适合程序员）
```bash
# 启动MCP服务器
mcp-server start --port 8000

# 或者用Python
python -m mcp_server --host localhost --port 8000
```

## 📍 第三步：验证是否成功

### 成功的标志：
- ✅ 界面显示绿色"已连接"
- ✅ 服务器状态显示"运行中"
- ✅ 没有红色错误提示

### 失败的标志：
- ❌ 显示红色"连接失败"
- ❌ 提示"无法连接到服务器"
- ❌ 界面一片空白

## 🔧 遇到问题怎么办？

### 问题1：找不到MCP在哪里
**解决**：
- 搜索"MCP"、"服务器"、"配置"
- 查看菜单栏的"工具"或"设置"
- 按 Ctrl+Shift+P (Mac: Cmd+Shift+P) 搜索"MCP"

### 问题2：开关按钮点了没反应
**解决**：
- 等待3-5秒（有时需要时间加载）
- 刷新页面重试
- 检查网络连接

### 问题3：显示"连接失败"
**解决**：
- 检查地址是否正确（比如 http://localhost:8000）
- 确保服务器在运行
- 尝试换个端口号（8001、8002等）

## 💡 快速测试

添加一个测试服务器：
```
名称：测试服务器
地址：http://localhost:8000
启用：是
```

如果能看到绿色状态，说明配置正确！
