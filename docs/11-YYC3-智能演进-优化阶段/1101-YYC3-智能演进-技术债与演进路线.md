## 一、技术债台账

| ID | 债务 | 类型 | 利息（持续成本） | 等级 | 偿还动作 |
| -- | ---- | ---- | ---------------- | :--: | -------- |
| TD-01 | 无版本控制 | 工程 | 不可追溯、不可回滚 | P0 | ✅ 已建立 `main` 与 GitHub 远程仓库 |
| TD-02 | 重复 `app.listen` | 缺陷 | 启动冲突 | P0 | ✅ 已移除重复监听 |
| TD-03 | compose 失效 | 配置 | 无法一键部署 | P0 | 修正服务清单 |
| TD-04 | 三套数据实现 | 架构 | 联调与测试翻倍 | P1 | ✅ 已收敛为 PG 唯一入口，Mongo/SQLite/Mock 服务已删除 |
| TD-05 | 密钥硬编码 | 安全 | 泄露风险 | P1 | `.env.example` + 轮换 |
| TD-06 | 无鉴权/校验 | 安全 | 数据可被污染 | P1 | 🟡 管理端 JWT + 参数校验已落地；播放写接口仍公开 |
| TD-07 | 前端大文件/重复组件 | 代码 | 维护成本高 | P2 | 拆分与去重 |
| TD-08 | CRA + JS | 技术栈 | 构建慢、无类型 | P2 | ✅ 已迁移 Vite 8 + React 19 + Vitest 5；TS 迁移待推进 |
| TD-09 | 移动端 / 营销占位 | 产品 | 期望落差 | P2 | 按路线图实现或下线（管理后台 MVP 已落地） |
| TD-10 | 种子脚本不匹配 | 数据 | 初始化失败 | P2 | 对齐 schema |
| TD-11 | 无监控/日志 | 运维 | 排障困难 | P2 | pino + Prometheus |
| TD-12 | 文档冲突 | 文档 | 决策混乱 | P2 | 归档 + 新索引 |
| TD-13 | 端口/年份/品牌残留 | 规范 | 一致性差 | P3 | 批量规范 |
| TD-14 | 媒体未压缩 | 性能 | 流量成本 | P3 | 转码 + 懒加载 |
| TD-15 | 依赖漏洞 43 项（3 critical） | 安全 | 供应链风险 | P1 | 升级 + audit 门禁 |

## 三、演进目标（12 个月）

| 维度 | 现状 | 目标 |
| ---- | :--: | :--: |
| 自动化测试覆盖 | ~5% | ≥ 80% |
| TypeScript 覆盖 | 0% | ≥ 90% |
| CI 流水线 | 无 | 全链路 |
| 部署方式 | 手工 | 一键/蓝绿 |
| 可观测性 | 无 | 指标+日志+追踪 |
| 安全高危 | 3+ | 0 |
| 文档标规达标 | 低 | ≥ 95% |

## 四、技术选型演进

| 领域 | 现状 | 目标 | 理由 |
| ---- | ---- | ---- | ---- |
| 构建 | Vite 8（已落地） | Vite 8 + Rolldown | 启动/构建更快，生态活跃 |
| 语言 | JavaScript + TypeScript 5.9 | 全量 TypeScript | 类型安全，契约稳定 |
| 测试 | Vitest 5 + RTL（前端）/ Jest 30（API） | Vitest + RTL + Playwright | 统一、快速、可 E2E |
| 状态 | useState | Zustand | 跨区块共享 |
| 样式 | styled-components 6 + Design Tokens | CSS Variables + Tailwind（可选） | 设计令牌统一 |
| 日志 | console | pino | 结构化 |
| 监控 | 无 | Prometheus + Grafana + Loki | 可观测 |

## 五、度量与复盘

| 指标 | 采集方式 | 频率 |
| ---- | -------- | ---- |
| 债务关闭数 | 台账状态 | 每迭代 |
| 测试覆盖率 | CI 报告 | 每次提交 |
| 构建时长 | CI | 每周 |
| 缺陷逃逸率 | 线上缺陷/总缺陷 | 每月 |
| 文档达标率 | 巡检脚本 | 每月 |

**复盘原则**：每关闭一个 P0/P1 债务，更新本台账与 `CHANGELOG.md`，并在周会通报。
