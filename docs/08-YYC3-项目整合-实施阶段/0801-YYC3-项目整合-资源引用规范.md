## 一、唯一原则

> **一切品牌、视觉与音频资产，只能来自 `public/`；一切代码引用，只能经过 `web_app/src/config/assets.js`。**

禁止在组件中硬编码 `/assets/**`、`http://localhost/**` 或第三方图床地址。

## 二、资产根路径

| 资产 | 根路径 | 说明 |
| ---- | ------ | ---- |
| 品牌主图 | `public/D-MusAI.png` | 1804×452，README/OG |
| Logo | `public/D-Music-icons/logo.svg` | 1024×1024，矢量 |
| 音乐字标 | `public/D-music.png` / `public/music.png` | 宣传物料 |
| 封面 | `public/D-cover/D-cover-01..08.jpg` | 作品封面 |
| 海报 | `public/D-poster/D-poster-01..06.jpg` | 活动/社交 |
| 音乐 | `public/D-Music/*.mp3` | 11 首 |
| 多端图标 | `public/D-Music-icons/{platform}/` | Android/iOS/macOS/tvOS/watchOS/Windows |

### 2.1 构建期同步（关键）

Create React App 只服务 `web_app/public`，而项目级资产的事实源在根 `public/`。因此 `web_app/scripts/sync-assets.js` 会在 `prestart` / `prebuild` 阶段自动同步白名单资产：

```bash
cd web_app
npm run sync:assets     # 手动同步
npm start               # 自动 prestart 同步
npm run build           # 自动 prebuild 同步
```

同步条目：`D-Music`、`D-Music-icons`、`D-cover`、`D-poster`、`D-MusAI.png`、`D-music.png`、`music.png`。

> 生成副本已写入 `.gitignore`，根 `public/` 始终是唯一事实源，禁止直接修改 `web_app/public/D-*`。

## 三、代码引用方式

```javascript
// web_app/src/config/assets.js
import ASSETS, { resolveCover, resolvePoster } from '../config/assets';

// 品牌
<img src={ASSETS.brand.logo} alt="M98" />
<img src={ASSETS.brand.banner} alt="M98 音乐宇宙" />

// 封面（按索引循环）
<img src={resolveCover(index)} alt={title} />

// 海报
<img src={resolvePoster(index)} alt={title} />

// 音频
<audio src={currentTrack.streamUrl} preload="metadata" />
```

**要点**

1. `PUBLIC_URL` 前缀保证子路径部署可用。
2. 中文与空格文件名通过 `encodeURIComponent` 编码。
3. 提供 `resolveCover/resolvePoster` 循环取值，避免越界与空图。
4. 所有 `<img>` 必须设置 `alt`；建议增加 `onError` 回退。

## 四、HTML / PWA 引用

| 位置 | 值 |
| ---- | -- |
| favicon | `%PUBLIC_URL%/D-Music-icons/logo.svg` |
| apple-touch-icon | `%PUBLIC_URL%/D-Music-icons/ios/AppIcon.appiconset/Icon-App-60x60@3x.png` |
| og:image | `%PUBLIC_URL%/D-MusAI.png` |
| manifest icons | `D-Music-icons/android/mipmap-xxxhdpi/ic_launcher.png`（192）、`playstore-icon.png`（512） |

## 五、文档引用

```markdown
<!-- 根目录 README -->
<img src="./public/D-MusAI.png" alt="M98 音乐宇宙">

<!-- docs/README.md -->
<img src="../public/D-MusAI.png" alt="M98 音乐宇宙">

<!-- docs/04-.../0401.md -->
<img src="../../public/D-MusAI.png" alt="M98 音乐宇宙">
```

> 相对路径层级必须与文档所在目录一致，否则 GitHub 渲染为破图。

## 六、多端图标映射

| 平台 | 入口 | 典型用途 |

## 七、校验命令

```bash
# 1. 禁止硬编码旧路径
grep -rn "/assets/" web_app/src && echo "违规" || echo "通过"

# 2. 检查资产是否存在
for f in public/D-MusAI.png public/D-Music-icons/logo.svg; do
  [ -f "$f" ] && echo "OK $f" || echo "MISSING $f"
done

# 3. 统计曲库
ls public/D-Music/*.mp3 | wc -l   # 期望 11

# 4. 检查图标尺寸
sips -g pixelWidth -g pixelHeight public/D-Music-icons/android/playstore-icon.png
```

## 八、违规处理

| 违规 | 处理 |
| ---- | ---- |
| 硬编码 `/assets/**` | PR 打回，改用 `assets.js` |
| 引用不存在的文件 | PR 打回 |
| 缺少 `alt` | 建议修正 |
| 使用外链图床 | 需评审并登记来源 |
