# 🚀 MCP 快速参考卡

## 核心概念

MCP = 服务器开关

- 开了 = 能用AI功能 ✅
- 关了 = 不能用AI功能 ❌

## 3步启用法

### 🎯 方法1：点击开关（最简单）

```text
1. 找到MCP配置界面
2. 找到服务器列表
3. 点击开关按钮
```

### 📝 方法2：改配置文件

```json
{
  "mcp_servers": [
    {
      "name": "我的服务器",
      "enabled": true
    }
  ]
}
```

### 💻 方法3：命令行

```bash
mcp-server start --port 8000
```

## 🔍 找MCP在哪里？

| 软件类型 | 位置           |
| -------- | -------------- |
| VS Code  | 侧边栏 → 扩展  |
| 网页应用 | 设置 → MCP配置 |
| 桌面应用 | 工具 → 配置    |

**找不到？** 搜索 "MCP" 或 "服务器"

## ✅ 成功标志

- 绿色"已连接"
- 状态显示"运行中"
- 没有红色错误

## ❌ 失败排查

| 问题       | 解决方案             |
| ---------- | -------------------- |
| 找不到MCP  | 按 Ctrl+Shift+P 搜索 |
| 开关没反应 | 等待5秒或刷新页面    |
| 连接失败   | 检查服务器地址       |
