## 一、审计结论

**整体安全等级：D（待整改）**。当前项目具备基础防护意识（helmet、cors、rate-limit），但认证授权体系未落地，密钥管理不合规，写接口暴露且缺少输入校验。**不建议在未整改情况下公网开放写接口。**

## 二、审计范围

| 类别 | 范围 |
| ---- | ---- |
| 配置 | `.env`、`docker-compose.yml`、Dockerfile |
| 应用 | Express 中间件、路由、错误处理 |
| 前端 | 资产引用、外链、播放器 |
| 依赖 | npm 依赖清单（未安装，未执行 audit） |
| 数据 | SQLite/Mongo 模型与种子数据 |
| 内容 | 媒体资产授权 |

## 三、发现清单

### 3.1 高危

| ID | 问题 | 位置 | 证据 | 整改 |
| -- | ---- | ---- | ---- | ---- |
| SEC-01 | 明文 `JWT_SECRET` | `api_service/.env` | `JWT_SECRET=m98_...2024` | 立即轮换；改由密钥管理注入；提交 `.env.example` |
| SEC-02 | 写接口无鉴权 | `POST /api/music/:id/play` | 任意请求可自增 | 增加限流 + 设备指纹 + 可选登录 |
| SEC-03 | 缺少参数校验 | 列表接口 | `limit/page` 直入查询 | 使用 `express-validator` 限制范围 |

### 3.2 中危

| ID | 问题 | 位置 | 整改 |
| -- | ---- | ---- | ---- |
| SEC-04 | 认证依赖空转 | `bcryptjs`、`jsonwebtoken` 已装未用 | 实现登录或移除依赖 |
| SEC-05 | 错误信息泄露 | `server.js` 错误中间件 | 生产关闭 `error.message` |
| SEC-06 | CORS 单值白名单 | `FRONTEND_URL` | 支持多域名数组 |
| SEC-07 | 无依赖漏洞扫描 | 全仓 | 实测 43 项漏洞（3 critical / 17 high） | CI 增加 `npm audit --omit=dev` 门禁 |
| SEC-08 | 无安全响应头策略细化 | `helmet()` 默认 | 增加 CSP、HSTS、Referrer-Policy |
| SEC-09 | 留言无内容审核 | 粉丝墙 | 增加敏感词/长度/频率限制 |
| SEC-10 | 并发计数丢失更新 | `SELECT→UPDATE` | 改原子自增 |

### 3.3 低危 / 合规

| ID | 问题 | 整改 |
| -- | ---- | ---- |
| SEC-11 | 媒体版权未书面化 | README/LICENSE 声明代码与媒体分离授权 |
| SEC-12 | 无隐私政策/用户协议 | 补充页面与文档 |
| SEC-13 | 无审计日志 | 记录关键写操作 |
| SEC-14 | 无备份加密 | 备份加密 + 访问控制 |
| SEC-15 | 开发端口暴露 | 生产仅暴露 80/443 |

## 四、依赖安全（实测）

在 `api_service` 安装依赖后执行官方源审计，结果如下：

```bash
npm audit --omit=dev --registry=https://registry.npmjs.org
# 43 vulnerabilities (3 low, 20 moderate, 17 high, 3 critical)
```

| 严重级别 | 数量 | 代表包 |
| -------- | :--: | ------ |
| critical | 3 | `fast-xml-parser`、`proxy-addr`、`tar` |
| high | 17 | `express`（直接）、`mongoose`（直接）、`sqlite3`（直接）、`cloudinary`（直接）、`validator`（直接）、`body-parser`、`jsonwebtoken` 依赖链等 |
| moderate | 20 | `uuid`、`@smithy/*` 等 |
| low | 3 | — |

> 说明：`npm audit fix --force` 会将 `sqlite3` 升至 6.x（破坏性变更），须在独立分支验证后升级。前端依赖尚未安装，未纳入本次统计。

**待补充**：`cd web_app && npm ci && npm audit --omit=dev`、`pip-audit`。

## 五、媒体版权合规

| 资产 | 版权归属 | 代码许可证 | 建议 |
| ---- | -------- | ---------- | ---- |
| `public/D-Music/*.mp3` | 董小姐 / 合作艺人 | 不适用 | 书面授权，禁止再分发 |
| `public/D-cover`、`D-poster` | 品牌方 | 不适用 | 书面授权 |
| `public/D-Music-icons` | 品牌方 | 不适用 | 仅用于本项目打包 |
| 源代码 | YYC³ Team | MIT | 可开源 |

**必须在 README 与 LICENSE 中声明**：MIT 仅覆盖源代码，媒体资产保留所有权利。
