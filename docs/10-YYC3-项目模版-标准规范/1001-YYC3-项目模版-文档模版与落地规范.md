## 六、追溯机制

1. 每次修改更新 `updated`，按 SemVer 调整 `version`。
2. 变更历史必须新增一行，禁止覆盖旧行。
3. 文档间引用使用相对链接，确保 GitHub 可跳转。
4. 新增文档在 `docs/README.md` 索引登记。
5. 重大决策写入 ADR，并在相关文档“关键决策”章节引用。

## 七、校验命令

```bash
# 1. 标头完整性
grep -L "^file: " docs/**/*.md

# 2. file 与文件名一致（人工抽查）
for f in docs/0*/*.md; do echo "$f ← $(grep -m1 '^file:' "$f")"; done

# 3. 标尾唯一性（应为 1）
grep -c '<p align="center">' docs/0*/*.md

# 4. 非法 tags 写法（应为空）
grep -rn "tags: \[[^]]*\],\[" docs/ || echo "PASS"

# 5. 品牌残留（应为空）
grep -rn "YanYuCloudCube-\|yanyucloud.com" docs/ || echo "PASS"
```

## 九、常见错误

| 错误 | 后果 | 修正 |
| ---- | ---- | ---- |
| `tags: [a],[b],[c]` | front matter 解析失败 | `[a, b, c]` |
| 文件名写 `YYC³` | 跨平台路径异常 | 使用 ASCII `YYC3` |
| 缺 `file` 字段 | 索引失效 | 补齐 |
| 资产路径层级错误 | 文档破图 | 按所在目录计算 `../` |
| 覆盖变更历史 | 追溯断裂 | 追加新行 |
